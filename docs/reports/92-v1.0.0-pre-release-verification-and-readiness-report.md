## 3. VIỆC 3 — Hiện Trạng Môi Trường Staging & Kế Hoạch Smoke Test

### 3.1. Phân Tích & Xác Nhận Hiện Trạng Môi Trường Staging

1. **Không có cụm máy chủ Staging cố định (Remote Persistent Staging)**:
   - Trong mã nguồn và DNS hạ tầng hiện tại **không tồn tại domain `staging.haihire.vn`** hoặc máy chủ cloud staging luôn bật sẵn.
   - Lý do: Kiến trúc của dự án được tối ưu chi phí theo mô hình **Ephemeral CI Staging Environment** (Môi trường Staging động theo yêu cầu trên GitHub Actions).

2. **Cơ chế Staging tự động qua GitHub Actions CI Pipeline**:
   - Kho lưu trữ sở hữu workflow hoàn chỉnh: [`.github/workflows/ci-staging.yml`](../../.github/workflows/ci-staging.yml) (Pre-Production CI dành riêng cho nhánh `staging`).
   - **Quy trình hoạt động tự động khi merge vào `staging`**:
     - Tự động khởi tạo dịch vụ thật trong Docker: **PostgreSQL 17.6-alpine**, **Valkey 8.0.2-alpine** (Redis), và **MinIO Object Storage** (được pin theo SHA256 an toàn tuyệt đối).
     - Chạy toàn bộ database migrations và nạp dữ liệu mẫu (`pnpm db:update` + `pnpm db:seed`).
     - Build gói mã nguồn production hoàn chỉnh (`pnpm build`).
     - Khởi động đồng thời cả frontend và backend trên cổng 13000 và 13001, đợi healthcheck sẵn sàng.
     - **Chạy toàn bộ bộ kiểm thử End-to-End (Playwright E2E Suite) tự động** trên trình duyệt Chromium headless mô phỏng toàn bộ hành trình người dùng thực tế.

Khi chuyển giao mã nguồn từ `dev` sang `staging` và trước khi deploy lên Production, thực hiện quy trình kiểm thử 3 bước:

- GitHub Actions kích hoạt `.github/workflows/ci-staging.yml`.
- Xác nhận toàn bộ 4 jobs CI: `11 CI Architecture Gates`, `Unit & Integration Tests (Coverage)`, `Playwright End-to-End Suite`, và `Production Build Verification` đều chuyển màu xanh lá (100% Passed).

#### Bước B — Chạy Local Production Staging Emulation (Nếu cần thẩm định UI trực quan):

1. Chạy hạ tầng sản phẩm local bằng Docker:
   ```bash
   pnpm docker:prod:up
   ```
2. Nạp dữ liệu seed demo:
   ```bash
   pnpm db:setup
   ```
3. Khởi động bản build production:
   ```bash
   pnpm build && pnpm start
   ```
