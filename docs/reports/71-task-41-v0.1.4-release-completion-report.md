## 4. Task #42: CI/CD Workflow Overlap Redesign

### 4.1 Problem Analysis

In Task #32, `pull_request` triggers were removed from `ci-dev.yml` and `ci-staging.yml` to prevent duplicate workflow executions during PR merges. However:

1. GitHub branch protection on `staging` required 4 checks (`11 CI Architecture Gates`, `Unit & Integration Tests (Coverage)`, `Playwright End-to-End Suite`, `Production Build Verification`).
2. When creating PRs targeting `staging`, these checks were never triggered, leaving them permanently "Expected" and blocking PR merges.
3. Operators had to manually disable `enforce_admins` on GitHub settings to force-merge promotions.

### 4.2 Architectural Solution

Implemented a dual-trigger architecture with conditional job skipping:

- **PR Trigger:** Workflows run full verification pipelines on PRs targeting `dev` and `staging`.
- **Merge Commit Skip:** Post-merge `push` events evaluate the commit message. If it contains `Merge pull request`, all downstream heavy jobs are bypassed, completing the workflow in ~10s.
- **Direct Push Support:** Direct pushes without PRs (e.g., hotfixes) continue to execute the full test pipeline.
- **Job Condition Matrix:**
  ```yaml
  if: |
    (github.event_name == 'pull_request' || 
     github.event_name == 'workflow_dispatch' ||
     (github.event_name == 'push' && !contains(github.event.head_commit.message, 'Merge pull request'))) &&
    needs.path-filter.outputs.code == 'true'
  ```

### 4.3 Workflows & Documentation Updated

1. [`.github/workflows/ci-dev.yml`](../../.github/workflows/ci-dev.yml): Added `pull_request: branches: [dev]` and conditional skip on `ci-gates`, `unit-tests`, and `docs-verify`.
2. [`.github/workflows/ci-staging.yml`](../../.github/workflows/ci-staging.yml): Added `pull_request: branches: [staging]` and conditional skip on `ci-gates`, `unit-tests`, `e2e`, `build`, and `docs-verify`.
3. [`CONTRIBUTING.md`](../../CONTRIBUTING.md): Updated CI triggers table and promotion descriptions.
4. [`docs/runbooks/ci-cd.md`](../runbooks/ci-cd.md): Documented the new trigger flow and conditional skip behavior.
5. [`docs/runbooks/branch-protection.md`](../runbooks/branch-protection.md): Removed manual workaround section and replaced with automated promotion flow.
