# Architectural Decisions Log (`DECISIONS.md`)

Authoritative Architecture Decision Records (`D-001` through `D-016`) governing **HaiHire Platform** design choices.

---

## Core Architecture & Toolchain (`D-001` – `D-008`)

| ID          | Decision                                                                 | Rationale & Implementation Reference                                                                                                                                                                                                                                                                                                                                 |
| :---------- | :----------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`D-001`** | **Prisma `7.10.1` Stable GA + `@prisma/adapter-pg`**                     | Standardized on Prisma `7.10.1` GA (eliminating pre-release ORM churn) backed by explicit `pg.Pool` + `PrismaPg` driver adapter ([apps/api/src/prisma/prisma.service.ts](../../apps/api/src/prisma/prisma.service.ts)) and [apps/api/prisma.config.ts](../../apps/api/prisma.config.ts). Enforced via [Prisma Version Policy](../runbooks/prisma-version-policy.md). |
| **`D-002`** | **Node `26` + `pnpm@12.18.0` Catalog + Turborepo**                       | Centralizes shared dependencies (`typescript`, `vitest`, `eslint`, `prettier`, `zod`, `tsx`, `@types/node`) in [pnpm-workspace.yaml](../../pnpm-workspace.yaml) with 24h `minimumReleaseAge: 1440` supply-chain hardening.                                                                                                                                           |
| **`D-003`** | **Dynamic `Organization.ownerId` Ownership Transfer**                    | Decoupled workspace ownership from static user roles onto `Organization.ownerId` (`Restrict` FK), allowing safe atomic ownership transfer without orphaned privilege states ([apps/api/src/auth/roles.guard.ts](../../apps/api/src/auth/roles.guard.ts)).                                                                                                            |
| **`D-004`** | **Express ESM Bundle (`esbuild` -> `dist/server.mjs`)**                  | Bundles `apps/api` into a single fast-booting Node 26 ESM entrypoint (`--packages=external --alias:@haihire/shared=...`) paired with explicit `@Inject()` decorators and `DtoPipe` so stripped design metadata never breaks DI or validation.                                                                                                                        |
| **`D-005`** | **Dual `DtoPipe` (`class-validator` + `@haihire/shared` Zod)**           | Enforces `expectedType` on class-validator DTOs and `.safeParse()` on shared Zod schemas ([apps/api/src/common/dto-validation.pipe.ts](../../apps/api/src/common/dto-validation.pipe.ts)), audited across all routes by `pnpm lint:dtopipe`.                                                                                                                         |
| **`D-006`** | **`AsyncLocalStorage` Transaction Propagation (`runInTransaction`)**     | Propagates active `PrismaPg` transaction handles automatically through asynchronous service layers (`apps/api/src/prisma/prisma.service.ts`) for atomic sagas and relational integrity.                                                                                                                                                                              |
| **`D-007`** | **Hard Row-Level Multi-Tenant Isolation & Static Gate**                  | Combines controller `tenantOrgId` forwarding, `TenantGuard`, and static AST/regex analysis ([scripts/check-tenant-scoping.ts](../../scripts/check-tenant-scoping.ts)) scoping per-method boundaries across all `8` business modules.                                                                                                                                 |
| **`D-008`** | **Mutable 5-Role / 41-Permission Matrix (`OrganizationRolePermission`)** | Preserves shared default role behavior (`@haihire/shared`) while supporting per-organization overrides cached for `60s` (`PermissionResolverService`) with strict `ADMIN` immutability.                                                                                                                                                                              |

## Frontend, Security, Reliability & CI (`D-009` – `D-016`)

| ID          | Decision                                                                       | Rationale & Implementation Reference                                                                                                                                                                                                                                                                        |
| :---------- | :----------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`D-009`** | **Next.js `16.4.5` `src/proxy.ts` + Standalone Output**                        | Replaces deprecated `middleware.ts` with Next.js 16 `proxy()` boundary ([apps/web/src/proxy.ts](../../apps/web/src/proxy.ts)), `output: "standalone"`, and Next rewrite rules (`apps/web/next.config.ts`) verified by `pnpm lint:nextjs-conventions`.                                                       |
| **`D-010`** | **Tailwind CSS `v4` (`oklch`) & Shadcn `base-nova` (`@base-ui/react` + `cn`)** | Adopts official Shadcn v4 `base-nova` primitives built on `@base-ui/react` with standalone `"cn"` (`^0.5.2`) class merging ([apps/web/src/lib/utils.ts](../../apps/web/src/lib/utils.ts)) and CSS-first `@theme inline` tokens in `globals.css`; unused `@radix-ui/*` packages are excluded.                |
| **`D-011`** | **TanStack Query v5, Axios URL Gatekeeper & Debounced SSE Sync**               | Centralizes query keys ([apps/web/src/hooks/query-keys.ts](../../apps/web/src/hooks/query-keys.ts)), intercepts concurrent `401` refreshes, blocks malformed `[object Object]` URLs, and batches `17` SSE `AppEventType` broadcasts over `100ms` windows (`createRealtimeInvalidator`).                     |
| **`D-012`** | **Two-Tier Localization (`vi` / `en`) & `64` Error Codes**                     | Combines strict compile/CI key parity across `en.ts`/`vi.ts` + `APP_ERROR_CODES` (`pnpm lint:i18n`, `pnpm lint:error-i18n`) with user-level preferences falling back to organization localization (`LocalizationProvider`).                                                                                 |
| **`D-013`** | **HttpOnly Cookie JWT + `tokenVersion` Session Revocation**                    | Stores signed access/refresh tokens in HttpOnly cookies plus client-synced session indicators, invalidating active JWTs immediately when `User.tokenVersion` increments on logout or password rotation.                                                                                                     |
| **`D-014`** | **Private MinIO Storage + BullMQ Saga Compensation & DLQs**                    | Isolates uploaded resumes inside private bucket `haihire-resumes` under `tenants/<orgId>/`, proxies downloads through tenant-checked endpoints, compensates failed application commits via `orphan-cleanup-queue` / `orphan-cleanup-dlq`, and routes exhausted transactional emails into `email-dlq-queue`. |
| **`D-015`** | **AES-256 Encrypted Integration Secrets & SSRF Protection**                    | Encrypts organization SMTP/email API keys and webhook tokens via `ENCRYPTION_SECRET`, authenticates `GET /metrics` with constant-time `METRICS_TOKEN`, and validates outbound webhook/SMTP hosts against SSRF.                                                                                              |
| **`D-016`** | **18-Gate Automated CI Pipeline (`pnpm check:all`)**                           | Enforces fail-fast env parity (`56` keys), tenant scoping, `DtoPipe`, i18n, doc link & drift integrity, non-decreasing test counts (`pnpm test:diff`), Vitest suites (`1527` tests), production builds, and Playwright E2E checks prior to release.                                                         |
