# HaiHire Enterprise ATS v0.1.3

**Release Date:** 2026-10-16
**Status:** Pre-release — Patch Release

## Highlights

Patch release focused on CI/CD optimization và documentation
reorganization. No code behavior changes.

## CI/CD Optimization (Task #32)

### Duplicate Trigger Fix

- Removed `pull_request` trigger từ `ci-dev.yml` và `ci-staging.yml`.
- Integration workflows giờ trigger chỉ on `push` post-merge.
- PR gating handled exclusively bởi `ci-feature.yml`.

### Path Filtering

- Integrated `dorny/paths-filter@v3` cho `ci-dev.yml` và `ci-staging.yml`.
- Docs-only changes bypass 11 gates, running lightweight `docs-verify`:
  - `pnpm lint:doc-links`.
  - `pnpm lint:i18n`.
- Runtime: ~30s (vs ~3m trước).

### Husky 3-Tier Restructure

| Tier       | Tool                  | Latency |
| ---------- | --------------------- | ------- |
| Pre-commit | `lint-staged`         | <5s     |
| Pre-push   | `lint` + `typecheck`  | ~25s    |
| CI         | 11 architecture gates | 2-3m    |

### Dependabot Optimization

- Schedule: Saturday 04:00 UTC (thay vì Monday).
- Added groups: production-dependencies, security-updates.
- Total groups: dev, production, security.

### Workflow Schedule Staggering

- `security-weekly.yml`: Monday → Wednesday 06:00 UTC.
- `e2e-weekly.yml`: target `main` → `staging`.
