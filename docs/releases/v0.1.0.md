# HaiHire Enterprise ATS v0.1.0 (Pre-release)

**Release Date:** 2026-10-14
**Status:** Pre-release — Active Development
**Stage:** Early Access

## About This Release

This is the first pre-release of HaiHire Enterprise ATS. The platform
is functionally complete and extensively hardened (20+ tasks, 606 tests,
11 CI gates), but remains in active development. Feedback from early
users will drive the roadmap toward a stable 1.0.0 release.

## What's Stable

- Core ATS workflows (jobs, candidates, applications, interviews)
- Multi-tenant architecture with complete data isolation
- Authentication and authorization (JWT + HttpOnly cookies)
- Saga pattern for distributed transactions
- Observability (metrics, alerts, correlation ID)
- Public careers portal with ISR caching

## What May Change

- Public API endpoints (may be added/modified)
- Database schema (migrations will be provided)
- UI/UX in dashboard
- Webhook payload format
- Error codes (may be refined)

## Known Limitations

- 5 "God Files" >400 lines (refactor in v0.2.0)
- Bundle size could be optimized (dynamic imports in v0.2.0)
- No OpenAPI/Swagger spec (planned v0.3.0)
- Account lockout not implemented (v0.3.0)
- 6 High CVEs in transitive dev dependencies (tracking upstream)

## Tech Stack

- Backend: NestJS 12 + Prisma 8 RC + PostgreSQL 17
- Frontend: Next.js 16 + React 19 + TanStack Query v5
- Infrastructure: Docker + Reverse Proxy (TBD) + Valkey 8 + MinIO
- Testing: Vitest + Playwright
