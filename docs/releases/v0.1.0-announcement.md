# HaiHire Enterprise ATS — v0.1.0 Early Access

**Release Date:** 2026-10-14
**Distribution:** Internal first, public after 1-2 weeks of internal testing

## TL;DR

Multi-tenant ATS, production-hardened, 606 tests passing. Not
API-stable yet. Feedback welcome.

## What is HaiHire?

A modern multi-tenant Applicant Tracking System for enterprise
recruitment teams.

## Why Pre-release?

We've completed extensive hardening (20+ tasks, 606 tests, 11 CI gates)
but want to validate with real users before committing to a stable API.

## What Works Today

- Complete recruitment pipeline (Applied -> Hired)
- Multi-organization support with data isolation
- Interview scheduling with scorecards
- Email automation with templates
- Multi-channel webhook notifications
- Public careers portal (SEO-optimized)

## What We're Working On

- Performance optimizations
- Additional integrations
- Enhanced analytics
- Admin tooling
