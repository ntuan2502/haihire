#### Ca 3 — Fix 3 (Xử lý lỗi xác thực HTTP 401 & chống rò rỉ tải file hỏng)

- **Vị trí kiểm thử**: Kanban Pipeline tuyển dụng (`/dashboard/jobs/773e57b9-e309-4f72-9ba0-99df8baf9a70/pipeline`).
- **Thao tác thực hiện**:
  1. Thiết lập chặn endpoint download tài liệu giả lập trả về mã `HTTP 401 Unauthorized` (mô phỏng token cookie hết hạn hoặc người dùng bị thu hồi quyền).
  2. Bấm mở tài liệu và kích hoạt thao tác tải xuống file CV.
- **Kết quả kiểm chứng**:
  - Hàm `downloadAuthenticatedFile` trong API client đã loại bỏ cơ chế tạo thẻ `<a>` fallback nuốt lỗi; lỗi 401 được quăng ngược lên caller (`throw err`).
  - Khối `try/catch` tại Pipeline bắt lỗi chuẩn xác và kích hoạt `toast.error(...)`.
  - Hệ thống không tải về bất kỳ file rỗng nào, giao diện giữ nguyên độ ổn định và không phát sinh crash.
- **Đánh giá**: **PASS** 🟢
